# Calculadora de Edad

Actividad 1 de revision integral de Laboratorio de Programacion (LPR): calculadora de edad exacta en Python y C++.

El programa valida la fecha de nacimiento (incluyendo anios bisiestos y dias por mes) y ajusta la edad segun si la persona ya cumplio anios a la fecha actual fija del ejercicio (8/7/2026).
